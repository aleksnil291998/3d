# 3D Print Marketplace - Маркетплейс для 3D печати

## Описание проекта

**3D Print Marketplace** — это полноценная платформа для сообщества 3D-печати, где пользователи могут:
- Заказывать услуги 3D-печати, моделирования и сканирования
- Покупать и продавать филаменты, 3D-принтеры, запчасти и комплектующие
- Приобретать готовые изделия и 3D-модели
- Взаимодействовать с продавцами через систему отзывов и рейтингов

Платформа объединяет заказчиков и исполнителей, создавая удобную экосистему для всех участников рынка 3D-печати.

## Технологический стек

- **Backend:** Python 3.12+, Django 5.x
- **Database:** SQLite (для разработки), PostgreSQL (рекомендуется для продакшена)
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Templates:** Django Templates
- **Static Files:** Django Static Files
- **Media Storage:** Локальное хранилище (можно настроить S3)
- **Authentication:** Django Authentication System

## Инструкция по запуску

### Требования

- Python 3.12 или выше
- pip (менеджер пакетов Python)
- virtualenv (рекомендуется)

### Шаг 1: Клонирование репозитория

```bash
cd /workspace
```

### Шаг 2: Создание виртуального окружения

```bash
# Перейдите в директорию проекта
cd 3d_marketplace

# Создайте виртуальное окружение (если еще не создано)
python -m venv venv

# Активируйте виртуальное окружение
# Для Linux/Mac:
source venv/bin/activate

# Для Windows:
# venv\Scripts\activate
```

### Шаг 3: Установка зависимостей

```bash
# Установите все необходимые пакеты
pip install -r requirements.txt
```

Если файл `requirements.txt` отсутствует, установите основные зависимости вручную:

```bash
pip install django>=5.0
pip install pillow>=10.0  # Для работы с изображениями
```

### Шаг 4: Настройка базы данных

```bash
# Примените миграции для создания таблиц базы данных
python manage.py migrate

# Создайте суперпользователя (администратора)
python manage.py createsuperuser
```

Введите данные администратора:
- Username: (ваш логин)
- Email: (ваш email)
- Password: (ваш пароль)

### Шаг 5: Запуск сервера разработки

```bash
# Запустите локальный сервер
python manage.py runserver 0.0.0.0:8000
```

Сервер запустится на адресу: `http://localhost:8000/`

### Шаг 6: Доступ к платформе

- **Главная страница:** http://localhost:8000/
- **Админ-панель:** http://localhost:8000/admin/
- **Регистрация:** http://localhost:8000/users/register/
- **Вход:** http://localhost:8000/users/login/
- **Каталог товаров:** http://localhost:8000/products/
- **Корзина:** http://localhost:8000/orders/cart/

## Первоначальная настройка

### 1. Создание категорий

После запуска проекта выполните следующие шаги:

1. Войдите в админ-панель: http://localhost:8000/admin/
2. Перейдите в раздел "Категории"
3. Создайте основные категории:
   - 3D-печать (услуга)
   - 3D-моделирование (услуга)
   - 3D-сканирование (услуга)
   - Филаменты
   - 3D-принтеры
   - Запчасти и комплектующие
   - Готовые изделия
   - 3D-модели

### 2. Регистрация продавца

1. Зарегистрируйтесь как обычный пользователь
2. В личном кабинете активируйте статус продавца
3. Заполните профиль продавца
4. Добавьте товары или услуги

### 3. Добавление тестовых данных

Для быстрого тестирования можно использовать Django shell:

```bash
python manage.py shell
```

## Конфигурация

### Настройки в `config/settings.py`

Основные параметры можно настроить в файле `settings.py`:

- `DEBUG` - режим отладки (True для разработки, False для продакшена)
- `ALLOWED_HOSTS` - разрешенные хосты
- `DATABASES` - настройки базы данных
- `MEDIA_URL` и `MEDIA_ROOT` - настройки медиа-файлов
- `STATIC_URL` и `STATIC_ROOT` - настройки статических файлов

### Переменные окружения (рекомендуется для продакшена)

Создайте файл `.env` в корне проекта:

```env
DEBUG=False
SECRET_KEY=your-secret-key-here
DATABASE_URL=postgresql://user:password@localhost:5432/dbname
ALLOWED_HOSTS=localhost,127.0.0.1,yourdomain.com
```

## Производительность

Рекомендации для продакшена:

1. **База данных:** Используйте PostgreSQL вместо SQLite
2. **Кэширование:** Настройте Redis или Memcached
3. **Статика:** Используйте CDN для статических файлов
4. **Медиа:** Настройте облачное хранилище (AWS S3, Google Cloud Storage)
5. **WSGI сервер:** Используйте Gunicorn или uWSGI
6. **Веб-сервер:** Настройте Nginx как reverse proxy
